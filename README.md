# 🌍 ClimateAI: Demanda de Climatización y Resiliencia Energética Urbana

Prototipo interactivo de Inteligencia Artificial y Analítica Predictiva para proyectar el aumento térmico urbano (`1850–2050`), estimar la demanda de refrigeración (**Cooling Degree Days - ASHRAE Base 18°C**) y emitir planes de acción prescriptivos para la red eléctrica.
